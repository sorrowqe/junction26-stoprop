- 2026-11-14 M0: `.gitignore` uses `/data/` (repo root only) instead of `data/`, otherwise `eval/data/dev|clean|symmetry` gold sets would be ignored too. `eval/data/test/` stays ignored (locked split).
- 2026-11-14 M1: Rule-based spans come from 4 patterns only (bandwagon phrases, vague "experts say", figure without a source in the same sentence, shouting capitals). They are always amber + experimental + confidence 0.3-0.45 and dropped at `strict`. Other lexical features are hints for the M2 prompt, never spans.
- 2026-11-14 M1: Experimental spans are returned by the API but hidden by default in the UI (principle 5). Every technique is `experimental: true` until M4 measures dev precision, so for now nothing is red. The UI shows "N experimental hints hidden" + a button to show them.
- 2026-11-14 M1: Profile `counts` / `density_per_1000` / `flagged_share` only count spans shown by default (non-experimental) that are not reported speech; "flagged" = red or amber. Extra profile fields: `genre`, `experimental {count, counts}`, `reported_speech`.
- 2026-11-14 M1: Paragraphs = blank-line separated blocks; if a text has no blank lines, each line is a paragraph (pasted articles often use single newlines).
- 2026-11-14 M1: Validator matches inside the given sentence only (no fallback to neighbouring sentences); normalizes NFKC, whitespace, quote marks, dashes, zero-width chars, ё->е; case-sensitive first, then case-insensitive fallback; repeated phrase -> first occurrence (or `occurrence=n`).
- 2026-11-14 M1: Reported speech = span inside a quote region (“” „“ „” «» "") with a speech verb (any of EN/ET/RU lists) within 100 chars before/after or a colon before it; scare quotes after "so-called / nn / так называемый" are NOT reported speech. Unclosed quote runs to paragraph end.
- 2026-11-14 M1: API offsets are Unicode code points (Python str indices); web/app.js converts them to UTF-16 indices for JS. Any JS API client must do the same (documented on /api).
- 2026-11-14 M1: Lexicon language is detected per paragraph (fallback: whole-text language), so mixed EN/RU/ET texts work.
- 2026-11-14 M1: Added `GET /api/techniques` (taxonomy for legend/tooltips), `app/taxonomy.py` (load + gate), `app/analyze.py` (pipeline orchestration), `app/pipeline/lexicons.py`. Request size cap 100,000 chars (413), then word truncation at 8,000 (prefix cut, so offsets stay valid).
- 2026-11-14 M1: Sample texts live in `web/static/samples.json` (fictional town "Harbourton") so tests can assert the neutral sample stays clean.
- 2026-11-14 v2 reconcile: removed `extension/` and `EXTENSION_ORIGINS`; no install-token/CORS code ever existed. Added `MODEL_EMBED` to `.env.example`.
- 2026-11-14 v2 reconcile: placeholder pages `/source` (M3), `/swarm` (M5), `/metrics` (M4); `/methodology` lists the principles until the M6 write-up; `/api` already has curl examples; FastAPI `/docs` enabled (Swagger UI assets come from its default CDN).
- 2026-11-14 v2 reconcile: stub modules `backend/app/swarm/*`, `eval/swarm/*`, `eval/data/raw/` per v2 layout. Analyze response gains `innocent_explanations` and `receipts` (empty until M3).
- 2026-11-14 v2 reconcile: kept the optional `lang` request field (default `auto`, not in the v2 request schema) - useful for eval and harmless.
- 2026-11-14 M2: openai 3.x is built on `httpx2` (not classic `httpx`); runtime code imports `httpx2` only (a test enforces this). Classic `httpx` stays a dev-only dependency for FastAPI's TestClient.
- 2026-11-14 M2: Paragraph cache stores the model's items with paragraph-LOCAL sentence indexes; validation re-runs on every read, so a cached paragraph inside a different text maps to the right ids/offsets. Empty results ([]) are cached; LLM failures are not cached (next request retries).
- 2026-11-14 M2: Uncached paragraphs are batched into ~1200-word chunks (one call each, max 3 concurrent); a repeated paragraph inside one text is sent once. Single-flight via an asyncio future per cache key.
- 2026-11-14 M2: Retry policy: client retries once on 5xx/timeout/connection error; tagger retries once if the reply has no parseable JSON array; then the chunk fails soft to heuristic spans for its paragraphs.
- 2026-11-14 M2: In `llm` mode only LLM spans are shown (heuristic hints go into the prompt); heuristic spans are used only for paragraphs whose LLM call failed, or in `heuristics_only` mode.
- 2026-11-14 M2: private=true reads the shared cache but never writes it and does not count sightings.
- 2026-11-14 M2: Budget day = UTC date. Budget mode: ok < 70% <= high < 100% <= over. Tokens = prompt + completion tokens from the API `usage` field.
- 2026-11-14 M2: Rate-limit client IP = rightmost X-Forwarded-For entry (added by Traefik); left entries are client-controlled. Limits are in memory (reset on deploy). Invalid requests (400/413/422) don't count.
- 2026-11-14 M2: If `data/` is not writable, SQLite falls back to in-memory (app still starts); `/api/health` shows `"storage": "memory"`. Fix on the server: `chown 10001:10001 /docker/stoprop/data`.
- 2026-11-14 M2: Pre-warm runs at startup in the background: the 3 demo samples (3 LLM calls the first time; then cached in SQLite for good as long as storage is "sqlite").
- 2026-11-14 M2: `prompt_version` = first 10 hex chars of sha256 of the rendered system prompt, so any prompt or taxonomy text change invalidates the cache automatically.
- 2026-11-14 M2: Innocent explanations are deterministic templates (per flagged label, genre, reported speech, rule-based source), shown only when something red/amber is flagged.
- 2026-11-14 M2: Pre-warm is fully inside try/except (incl. the budget check) and only logs on failure; tests start the real lifespan with a hanging and a crashing router and require /api/health to answer immediately.
- 2026-11-14 M3: URL fetching uses httpx2 with a custom httpcore2 network backend (`GuardedBackend`) that resolves the host, rejects any non-public answer, and connects to the vetted IP itself (closes the DNS-rebinding gap); TLS still verifies against the hostname. Wired in by replacing the transport's `_pool` (httpx2 has no public knob) - covered by tests, pinned versions.
- 2026-11-14 M3: Blocked: non-http(s), credentials in URL, backslashes/whitespace, ports other than 80/443/8080/8443, single-label and local names (localhost, *.local, *.internal, ...), non-canonical numeric hosts (decimal/hex/octal/short IPv4), and every non-public IP incl. CGNAT, metadata, documentation ranges, multicast, IPv6 ULA/link-local, IPv4-mapped, 6to4, NAT64 and Teredo. Host is checked before port so "localhost:8000" reports "private address".
- 2026-11-14 M3: Redirects are followed manually (max 3), each hop re-checked; 8 s total deadline (asyncio.timeout), 2 MB streamed cap, only text/html and application/xhtml+xml; `trust_env=False` so environment proxies can't bypass the checks.
- 2026-11-14 M3: Main text via trafilatura (favor_precision; ~26 MB RAM, lazy import) - it never fetches anything itself; we pass it HTML we fetched. < 25 words extracted -> friendly 422 "paste the text instead".
- 2026-11-14 M3: Registrable domain via `tld` with its bundled offline Public Suffix List (no runtime downloads).
- 2026-11-14 M3: Receipt TTLs: the spec numbers are the SOFT TTLs; hard = 4x soft (rdap/archive/cert 7 d / 28 d, fact_checks 12 h / 48 h). Errors and not_found: 10 min. Budget mode high/over doubles soft TTLs. Lookalike is recomputed every time (pure function of outlets.yaml). Fact-checks without a key and syndication are "not_checked" and never cached.
- 2026-11-14 M3: Receipts carry `flag` (ok / warning / neutral) besides `status`, so the UI can show an icon + label; young domains (< 180 d registered, < 90 d first archive/cert) are "warning", everything else factual is "neutral"; only "official outlet domain" is "ok".
- 2026-11-14 M3: Lookalike rules ignore 2-letter outlet names (dw, ft, ap, dr, hs) - too many innocent collisions; typo distance only for names with >= 5 letters (2 typos for >= 9). Known false-positive class: dictionary words one letter from an outlet name (e.g. lemonade vs lemonde) - text says "resembles", not "is fake".
- 2026-11-14 M3: Fact-check receipt = keyword search (page title, else domain) and says so ("may not be about this exact page").
- 2026-11-14 M3: /api/analyze with url and no text fetches the page and returns the extracted `text` (offsets refer to it) + `source`; with text AND url it analyzes the text and uses the url only for receipts. Receipt failures never fail an analysis (note instead). The analyze rate limit is charged before fetching, so blocked SSRF probes count too.
- 2026-11-14 M3: Tests block real DNS and HTTP with a BaseException (cannot be swallowed by `except Exception` in app code).
- 2026-11-14 pre-M4: Gold CSV = one row per span (`id, source, lang, genre, kind, topic, direction, text, quote, label, start, end, reported_speech, ok, notes`); a text without spans has one `label=none` row. `source` in {synthetic, semeval, human}; `ok` empty = keep, `n` = drop (sheet_to_jsonl.py, M4). UTF-8 with BOM so Excel/Sheets show ET/RU correctly. Shared code in `eval/goldcsv.py`.
- 2026-11-14 pre-M4: Synthetic generator uses `gpt-5.5-eu` (CLAUDE.md prefers -eu variants of the requested gpt-5.5; non-Claude to avoid shared bias with the tagger; Claude models are refused). reasoning_effort=low, JSON response format, replies cached on disk (eval/data/cache/, gitignored); 5 specs per call, one repair round for invalid items, then the item is dropped and reported.
- 2026-11-14 pre-M4: Specs are seeded and fixed in advance: 45 manipulative (30x two + 15x one technique, every technique exactly 7-8 times, sides a/b 23/22 across 6 topics with paired opposing stances), 30 hard negatives (10 emotional factual, 10 quoting a politician's loaded words = rs spans, 10 fair opinion with balance spans), 15 claim items (5 each unsupported/supported/balance); EN 50 / ET 20 / RU 20. Fictional people/parties/places only.
- 2026-11-14 pre-M4: Reported speech in gold: marker `[[label|phrase|rs]]` -> row with the technique label and `reported_speech=y` (expected: not counted against the text; must not raise FPR). Validation requires rs phrases to sit inside quotation marks.
- 2026-11-14 pre-M4: A generated item is rejected if markers are malformed, a label is unknown, a span crosses a sentence boundary (per our segmenter - our validator could never match it), length is outside 35-170 words, the detected language differs, planted techniques are missing, or unrequested techniques appear.
- 2026-11-14 pre-M4: SemEval-2020 Task 11 corpus is freely downloadable (Zenodo 3952415, CC BY 4.0, md5-pinned). 8 classes map 1:1; Repetition, Flag-Waving, Slogans, Thought-terminating cliches have no equivalent and the merged classes (Whataboutism/Straw Men/Red Herring, Bandwagon/Reductio) would be lossy -> paragraphs containing them are skipped, as are spans crossing paragraphs. Sample = 70 paragraphs with spans + 30 without, headlines skipped. SemEval annotates techniques inside quotes too, so `reported_speech` is left empty (unknown) for SemEval rows.
- 2026-11-14 pre-M4: make_synthetic sends reasoning_effort=low and max_completion_tokens=8000 per call, logs real usage incl. reasoning tokens, and stops after the FIRST real call if it used more than 2x the per-call token estimate (cached reply kept; re-run continues from cache).
- 2026-11-14 pre-M4 (requirement for M4, from Aleksandr): for source=semeval, run_eval.py reports two scores - "strict" (spans our system marks as reported_speech do NOT count as detections, per our principle 3) and "lenient" (they do, matching SemEval's annotation, which labels techniques inside quotes too); /metrics explains the difference in one sentence.
- 2026-11-14 scope: evaluation is ENGLISH ONLY for now (run_eval.py, ai_review.py, sheet_to_jsonl.py default to lang=en; ET/RU rows stay in the CSVs, excluded and counted as "not evaluated (language)"). `config/languages.yaml` marks only en as evaluated; other languages get `language_evaluated: false`, strict sensitivity when the request does not choose one (UI "Automatic"), and a one-line note. /metrics shows a language coverage table.
- 2026-11-14 policy: attributed INDIRECT speech counts as reported speech (validate.py `_indirect_attribution`, tagger prompt rule 5, CLAUDE.md §1.3): "X said (that)…", "X called it…", "according to X, …", "…, X said", ET "X sõnul…", "X ütles, et…", RU "по словам X…", "X заявил, что…" - same sentence. Not reported speech: first-person ("I said that"), vague attributions that are themselves techniques ("experts say", "many people are saying", lexicon vague_authority/bandwagon), "so-called", and spans containing the reporting verb. Known limit: a speech verb in an unrelated clause of the same sentence also counts. The prompt change invalidates the paragraph cache (new prompt_version) -> production pre-warm makes 3 Haiku calls once after the next deploy.
- 2026-11-14 AI review (no human review planned): reviewers gemini-3.5-flash-eu + mistral-medium-3.5-eu (neither GPT = generator nor Claude = tagger), English synthetic rows + English symmetry pairs (a pair = one item), 6 items per call -> 22 calls. Consensus only: ai_ok y/n when both agree, blank otherwise (excluded + counted). reported_speech corrected only when both propose the same value. Hard negatives / claim items / neutral pairs: both reviewers find an unmarked author technique -> n, one -> excluded; manipulative items: unmarked techniques are informational. Asymmetric pair (both say so) -> n. Cohen's kappa overall and per label in eval/results/ai_review.json and on /metrics with the disclosure "validated by two independent model families, consensus only, not human-verified". The script refuses to rewrite a CSV that is open in LibreOffice/Excel (lock file).
- 2026-11-14 sheet_to_jsonl: row decision = `ok` if filled, semeval/human rows kept as labelled, else `ai_ok`; blank -> excluded. An item is used only if all its rows are accepted. Seeded 70/30 dev/test split by item-id hash (test gitignored, LOCKED). Clean sets: SemEval paragraphs without spans ("semeval_none") and English synthetic hard negatives, reported separately (no clean.csv).
- 2026-11-14 run_eval: predictions = all gated spans at sensitivity "broad" by default, including experimental ones; strict (reported speech not counted, gold reported_speech=y removed) and lenient scores for every source; FPR "any" (red/amber) and "techniques" (claims excluded), with spans the gold itself marks (claims, balance, quoted words) not counted as false positives; separate eval SQLite cache (eval/data/cache/eval.db); dev runs of one model update dev_precision/experimental for labels with >= 5 predictions (text edit, comments kept).
