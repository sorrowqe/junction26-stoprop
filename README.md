# Stoprop

> Stoprop: see the spin before it sees you. We flag the tactics, not the opinions.

A web service (web app + public API) that detects signs of propaganda and coordinated
manipulation online, three ways:

1. **Analyze** a text or URL: highlights manipulation techniques and explains each one.
2. **Check the source**: plain-English provenance receipts for a URL or domain.
3. **Swarm mode**: upload a batch of posts and detect coordinated behaviour (text reuse,
   timing, account similarity, amplification) - never from a single post.
