# Lexicons

One file per language. `[section]` headers, one entry per line, `#` comments.
Matching is case-insensitive on whole words; `*` at the end of a word = any word ending
(for inflected ET/RU forms); multi-word entries match any whitespace between words.
Russian `ё` is matched as `е`, so write entries with `е`.

These lists produce **hints**, not verdicts (CLAUDE.md §4 step 2). Keep them small and
about *how* something is said, never about which side or topic.

Sections: emotive, intensifier, absolutist, ingroup, outgroup, attribution, speech,
bandwagon, vague_authority, balance, opinion, first_person, scare.
