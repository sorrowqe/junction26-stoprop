How these numbers are measured (and their limits)

  • Language scope: Stoprop accepts English and other languages; quantitative accuracy benchmarks have been measured on English so far, while other languages use the same conservative Strict default.
  • Reference datasets: evaluated on human-annotated news paragraphs from SemEval-2020 Task 11 (Da San Martino et al., 2020, arXiv:2009.02696) and controlled multi-technique passages, alongside clean-news and emotional/opinion hard-negative controls.
  • Exact-quote verification: every highlighted passage is verified character for character against the input text; any unverified quote is automatically discarded before display.
Stoprop labels techniques and behaviours, never people, outlets or viewpoints.
