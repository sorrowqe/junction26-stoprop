For developers

API

Everything the web app does is available as a JSON API. Interactive reference: /docs.

Analyze a text

curl -s https://stoprop.tech/api/analyze \
  -H 'Content-Type: application/json' \
  -d '{"text": "Everyone knows the plan failed.", "sensitivity": "balanced", "private": false}'

Returns highlighted spans (start/end offsets, label, colour, confidence, plain-language explanation, reported_speech, experimental), a profile, innocent_explanations, mode (llm or heuristics_only) and token cost. sensitivity: strict (default) | balanced | broad (no confidence filter); measured trade-offs on Metrics. private: true means the text is not written to the shared cache.

Offsets are Unicode code points (Python string indices). In JavaScript, convert them before slicing strings that contain emoji or other characters outside the Basic Multilingual Plane.

Analyze a link

curl -s https://stoprop.tech/api/analyze \
  -H 'Content-Type: application/json' \
  -d '{"url": "https://www.bbc.com/news/..."}'

Stoprop fetches public web pages only (private, local and cloud-metadata addresses are refused, every redirect is re-checked, 8 s / 2 MB limits), extracts the main text, and returns it as text together with source (title, final URL, date) and receipts for the domain.

Verify claims in a text

curl -s -X POST https://stoprop.tech/api/verify \
  -H 'Content-Type: application/json' \
  -d '{"text": "According to Reuters, emergency grid rationing starts Monday."}'

Extracts up to 3 check-worthy factual claims (+ cited source), searches cited domains and independent news/web indexes (Brave Search + Oxylabs failover), reads candidate articles SSRF-safely, and returns verbatim-verified evidence quotes with stance (corroborated | contradicted | cited_source_not_found | no_reports_found | not_checked).

Check a source (provenance receipts & live page audit, 0 AI calls)

curl -s https://stoprop.tech/api/receipts \
  -H 'Content-Type: application/json' \
  -d '{"url": "https://www.nytimes.com/"}'

Returns domain milestones (RDAP / ccTLD port-43 WHOIS registration, Wayback first capture, Certificate Transparency via crt.sh + CertSpotter), live HTML page audit (HTTPS, About/Contact/Policy transparency links, author byline, brand-impersonation check, and outbound_links domain network), 8-watchdog fact-check search, and open-web verbatim copy detection.

Swarm mode (coordinated behaviour across threads & channels)

curl -s -X POST https://stoprop.tech/api/swarm \
  -H 'Content-Type: text/csv' --data-binary @posts.csv

# public thread or channel link (Reddit, Telegram t.me, Bluesky, Hacker News, YouTube)
curl -s -X POST https://stoprop.tech/api/swarm -H 'Content-Type: application/json' \
  -d '{"url": "https://www.reddit.com/r/worldnews", "tag_clusters": true}'

# cross-channel check: up to 50 public links (e.g. multiple Telegram channels); "stream": true sends NDJSON progress
curl -s -N -X POST https://stoprop.tech/api/swarm -H 'Content-Type: application/json' \
  -d '{"urls": ["https://t.me/euronews_en", "https://t.me/dwnews"], "stream": true}'

Columns id, author, timestamp, text (optional url, author_created_at, platform), CSV or JSON, max 2000 posts / 2 MB, processed in memory and never stored. Returns clusters (groups of accounts posting the same or near-identical text), each with a verdict (likely_coordinated | worth_watching | organic_looking | insufficient_data), families (T text reuse, S timing, A accounts, M amplification), evidence_for, evidence_against, innocent_explanations, authors and a timeline; plus skipped rows with reasons. deep (embeddings) and tag_clusters (max 10 AI calls) cost credits and are off by default.

Trace a post

curl -s -X POST https://stoprop.tech/api/trace \
  -H 'Content-Type: application/json' \
  -d '{"url": "https://bsky.app/profile/bsky.app/post/3mzhhvhjfwk22"}'

Body {"text": ...} or {"url": ...} (add "stream": true for progress lines). Returns the fingerprints searched, coverage (what was and was not searched), spread (first seen, timeline, websites with domain checks, accounts), the verdict and cluster evidence, and every kept result in copies. Public data only, nothing stored, 5 traces per hour.

Clean the traffic (server-log bot & scraper inspector)

curl -s -X POST https://stoprop.tech/api/traffic \
  -H 'Content-Type: text/plain' --data-binary @/var/log/nginx/access.log

Parses Nginx/Apache Combined logs, Caddy/Traefik JSON logs, or CSV in memory (never stored), enriches public IPs with Shodan InternetDB (open ports, tags, CVEs, rDNS), RIPE NCC ASN, and optional VirusTotal, separates credential stuffers, vulnerability scanners, spoofed search crawlers and bulk AI scrapers from real visitors (including shared office NAT), and outputs ready-to-paste Hostinger .htaccess, Nginx, and ufw rules.

Taxonomy

curl -s https://stoprop.tech/api/techniques

Returns all 14 taxonomy entries (label, human-readable name, kind, color, plain-English definition, example, and calibrated thresholds for strict, balanced, and broad).

Health and AI budget

curl -s https://stoprop.tech/api/health

Rate limits

Per client IP, per hour: analyze 30, receipts 60, verify 10, swarm 10, trace 5, traffic 30, feedback 30. Over the limit you get HTTP 429 with a plain message.

Evaluation results: GET /api/metrics.
